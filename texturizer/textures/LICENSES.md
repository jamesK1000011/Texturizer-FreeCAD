# Texture library licences

The heightmaps in this folder come from BumpMesh (stlTexturizer) by Stefan Hermann (CNC Kitchen),
github.com/CNCKitchen/stlTexturizer, resized to the 512 px BumpMesh samples them at (`<name>.png`)
with 128 px thumbnails (`thumbs/`). `catalog.json` lists each one's BumpMesh name, category, default
tile size and credit. The six Filter Forge textures (Basket, Brick, Bubble, Crystal, Leather 2,
Weave 3) are not included: their licence does not cover redistribution here.
