# Icon credits

Icons adapted from Tabler Icons (MIT, tabler.io) and Pictogrammers Material Design Icons (Apache-2.0, pictogrammers.com). FreeCAD's own icons are used by name from FreeCAD.

Texturizer is based on BumpMesh by Stefan Hermann (CNC Kitchen); the icons are new drawings and carry no BumpMesh artwork.

Each icon here is hand-drawn on a 64×64 canvas in FreeCAD's Artwork Guidelines style (Tango palette, 2 px dark outline, 2 px inner highlight, light from the top left). The glyph named for each file is the composition it follows; its paths were redrawn, not copied. The licence texts are in `LICENSES/` (MIT for Tabler, Apache-2.0 for MDI); the files themselves carry this add-on's licence (see `REUSE.toml`).
